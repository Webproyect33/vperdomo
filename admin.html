Conexión con GitHub

🔐 Seguridad: Usa un Fine-grained token limitado solo a este repositorio y con permiso "Contents: Read and write". El token se guarda en tu navegador (localStorage) y nunca se sube a GitHub.

🔑 Token de GitHub

Créalo en: GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token.
Permisos: Repository access → Only select repositories (tu repo) → Permissions → Contents → Read and write.
